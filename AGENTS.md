# AGENTS.md — youtube-to-notes

Правила работы в этом репозитории (коротко).

- Минимальные изменения: решаем поставленную задачу, без фич «на будущее».
- Evidence/correctness first: сначала проверяем фактическое поведение (тесты,
  реальный запуск), потом считаем задачу выполненной. Не симулировать PASS.
- Pipeline строго subtitles-first: если подходящие субтитры есть — аудио не качаем,
  Whisper не запускаем. Whisper — только fallback.
- Milestone 1 = transcript. Никакой LLM/Obsidian интеграции, пока явно не запрошено.
- Не добавлять архитектуру/абстракции без обнаруженной необходимости.
- Не выполнять `git commit` / `git push` без явного разрешения пользователя.
- Изменения проходят валидацию: `python -m pytest` + релевантные ручные проверки.
- `output/` — генерируемые данные: не коммитить, не индексировать.
- Рабочее окружение: `.venv` (`.venv/bin/python -m pytest`, `.venv/bin/youtube-to-notes`).
